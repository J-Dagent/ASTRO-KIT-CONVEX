# Astro Kit Convex domain

This glossary names the small set of product concepts shared by the authentication and billing examples.

## Language

**User**:
An authenticated person who can access protected application routes.
_Avoid_: Account, member

**Polar customer**:
The billing identity that Polar links to one User.
_Avoid_: User, account

**Subscription**:
A Polar-managed recurring entitlement associated with a Polar customer and product.
_Avoid_: Plan, membership

**Realtime note**:
A short shared teaching record used to demonstrate a reactive Convex query and mutation.
_Avoid_: SQL row, CRUD item
