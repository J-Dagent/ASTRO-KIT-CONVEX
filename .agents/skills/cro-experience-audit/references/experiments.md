# Experiment rules

A test needs:
- a falsifiable hypothesis;
- one primary variable unless explicitly a route/compound test;
- primary frontend metric;
- downstream business/CRM signal when relevant;
- minimum data condition;
- decision horizon or rule;
- rollback;
- owner.

Prioritize route/offer mismatch, message match/above-fold clarity, CTA/form friction, proof, objections, then presentation polish.

Recommend at most 1–3 next experiments. Preserve the existing control and assignment mechanism when the experiment is implemented. A page becomes the new control only after the agreed decision rule is met.
